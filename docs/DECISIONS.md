# Decisions

This file is where Claude, the AI assistant that plans the work, puts decisions only you can make when no decision board is set up. A decision board is a private web page listing choices waiting on you; creating one needs Claude's Artifact tool, which publishes pages online. You answer here by writing under **Answer**. Save the file, then tell Claude you have answered; it reads this file before acting on any card here.

This file is saved with your project and pushed online, so anyone can read it if the project is public: never write passwords, keys or personal details here.

## How a card looks

A card is one question with its own number, such as D-01, so you can refer to it easily. **Why** explains why the choice matters. **What is true today** gives the known facts. **Options**: a card gives two to four options, lettered a, b, c, d; there is no "Other" option, because you can always write your own answer instead. **Recommended** starts with the option's letter, then one sentence saying why; it is Claude's suggestion, not your answer. To answer, write under **Answer** the letter of the option you pick, such as `a`. To give your own answer instead, write `Other:` followed by it. You can add an explanation after either.

Claude numbers your real cards from D-02 and never reuses a number. If you later set up a decision board, Claude moves your cards onto it and leaves this example out.

The card below is an example, not a decision about your project.

**Why**

Choosing a main colour would give the example site's buttons and headings a consistent appearance.

**What is true today**

In this example, no main colour has been chosen.

**Options**

- a: Blue — use blue for the main buttons and headings.
- b: Green — use green for the main buttons and headings.

**Recommended**

a — Blue is a common, safe starting colour for buttons and headings.
